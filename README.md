## 

## *Projet réalisé dans le cadre du module Projet SI Java à ESIEE-IT pour l'année 2026-2027.*

## 

## *## Technologies utilisées*

## 

## *- Java 21*

## *- Gradle 8.14.3*

## *- JUnit 5*

## *- Git et GitHub*

## 

## *## Prérequis*

## 

## *- JDK 21 installé*

## *- Git installé*

## *- Aucun Gradle à installer : le projet utilise Gradle Wrapper.*

## 

## *Cloner le dépôt :*

## *```*

##

## *Sous Windows :*

## 

## *```cmd*

## *gradlew.bat run*

## *```*

## *## Exécution des tests*

## 

## *Sous Windows :*
